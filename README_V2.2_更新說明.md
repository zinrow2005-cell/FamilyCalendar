# 家日曆 V2.2｜蠟筆手繪手機快捷操作優化版

這是家日曆 V2.1 的前端改版，新增手機專用快捷導覽，但保留原本的月曆、個人常用事項、時間與底色、醫院不規則批次排班、家庭照片、重複事項期限和 Google Sheets + Apps Script 家人同步。

## 新版操作

- 手機下方固定四個入口：**日曆、常用事項、批次排班、家人成員**。
- 點「常用事項」可先挑日期、再挑家人；只看該位家人的常用項目。點項目後系統開啟原本的新增表單，帶入標題、日期、時間、底色、地點、備註，使用者確認後才儲存。
- 若尚無清單，可直接點「管理常用清單」建立，或點「自訂新事項」。
- 點「家人成員」可直接切換要顯示的行程，也可以恢復「全部顯示」，或進入家庭成員管理。
- 點「批次排班」直接打開原本不規則值班表，不會自動預設固定週期。
- 右下角「＋」仍可直接新增一般事項；手機表單儲存列固定於表單下緣，更容易操作。
- 桌機和平板維持原本操作，不會出現手機底部導覽。

## 安全升級順序

1. **先在目前版本下載完整 JSON 備份**。如果手機、電腦有尚未同步的資料，兩邊都要備份並確認雲端狀態。
2. 解壓縮 ZIP，將 `index.html`、`styles.css`、`app.js`、`sw.js`、`manifest.webmanifest`、`illustrations/`、`icons/` 一起上傳 GitHub 專案，保持路徑不變。
3. 使用 GitHub Pages HTTPS 開啟，確認畫面版本 **V2.2**。若裝置仍顯示 V2.1，先完全關閉 PWA 後重開；必要時清除站點快取，**不要在未備份前清除站點資料**。
4. 手機先新增一筆測試事項，確認電腦端能從 Google Sheets 同步收到，再正式使用。

## Apps Script 需要重新部署嗎？

**不需要。** 本版只修改前端 UI，ZIP 內的 `AppsScript/Code.gs`、`Bridge.html` 完全沿用 V2.1，Google Sheets 分頁和家庭共用密鑰都不必更改。若你使用的 Google Apps Script 本來還沒成功讓手機同步，更新這版前端不等於修復後端問題，需另外排除連線錯誤。

## 關於備份及雲端

沿用既有 localStorage + Google Sheets 同步邏輯，沒有修改資料庫結構。家人照片、既有行程、重複例外日和批次排班記錄不需要重新建立。**目前的雲端同步不是經過這次新版的真實雙裝置連線測試**，只確認程式未改動，請發布後自行確認。

## 檔案

- `index.html`：可直接做靜態頁面的完整入口，主要 JavaScript 已內嵌以降低漏載風險。
- `app.js`、`styles.css`：同版原始程式副本供維護（主要畫面由 index.html 的內嵌腳本啟動）。
- `illustrations/crayon-theme.css` 與 SVG：蠟筆繪畫風資產。
- `sw.js`、`manifest.webmanifest`、`icons/`：PWA 快取與安裝圖示。
- `AppsScript/`：舊版同步後端備份，無須重新部署。
- `QA_TEST_REPORT.md`、`QA_RESULTS_V2.2.json`：測試紀錄。
