# 家日曆 V2.4｜臺灣國定假日自動顯示

## 本版更新

這是完整的 V2.3 延續升級，保留蠟筆手繪主題、家庭照片、個人常用事項、每週／每月重複事項、醫院不規則排班，以及 Google Sheets／Apps Script 全自動家庭同步。**未修改家庭行程資料格式，也未修改 AppsScript/Code.gs 或 Bridge.html。**

- 月曆格子的日期下方，自動顯示「國慶日」「春節」「清明節」「補假」等名稱；與原本家庭事項分開。
- 週檢視同樣顯示，清單檢視會顯示有假日的日期（即使沒有家庭行程）。
- 點選日期，右側／手機下方的當日詳情會出現政府假日資訊，長節日名稱可完整閱讀。
- 淡珊瑚蠟筆標籤：國定假日；奶油黃色：補假／調整放假；灰紫色：政府日曆註記補班。
- 月曆下方可勾選「🇹🇼 顯示國定假日」，預設開啟；選擇只存在目前裝置，不同步干擾家人。
- 週末沒有官方節日名稱時不額外建立標籤；醫院值班、工作休假仍依使用者自行輸入為準。

## 資料來源與更新

- 官方原始資料：行政院人事行政總處，[中華民國政府行政機關辦公日曆表](https://data.gov.tw/dataset/14718)。
- 前端採用依官方 CSV 整理的 [ruyut/TaiwanCalendar 年度 JSON](https://github.com/ruyut/TaiwanCalendar)，從 jsDelivr CDN 依瀏覽年度載入，並將每年資料快取於各裝置的瀏覽器（約每 7 天檢查一次）。
- 已內建 2026 年有名稱的假日與補假作為離線備援。2027 年等已公布年度需要首次連網取得，成功後可離線快取；**尚未公布的年度不會擅自推測農曆假日或補假。**
- 若 CDN 無法連線，APP 仍可正常查看、安排日曆；當年快取存在時仍會顯示。若該年度尚無快取，畫面會提示「本年度假日資料尚未取得」。
- 本功能不把國定假日存入家庭行程，不會上傳到 Google Sheets，也不會把政府機關適用的假期誤當成醫院員工休假。

## 直接升級 GitHub Pages

1. 建議先在舊版 APP 匯出 JSON 完整備份，包含尚未同步的手機與電腦端各自資料。
2. 解壓縮 V2.4 ZIP，把專案檔案**包含 `holidays.js`、`holidays.css`、`illustrations/`、`icons/`、`sw.js`**一起上傳到同一個 GitHub Pages 專案。
3. 更新後重新整理頁面，確認頁首顯示 `V2.4`，10 月查看 10/9、10/10、10/25、10/26 的標籤。
4. 若 PWA 還是舊畫面，請先關閉 APP 後重新開啟，必要時清除該網站舊快取（清除瀏覽資料前先備份本機行程）。
5. **不需修改原 Google Sheets、不需重新部署 Apps Script、不需更換家庭金鑰。**

## 檔案

- `index.html`：完整可執行單頁 APP（包含原本日曆邏輯）。
- `app.js`：同步保留的主要 JS 原始程式。
- `holidays.js`：年度載入、解析、驗證、快取、離線備援及顯示設定。
- `holidays.css`：月曆標籤、清單、當日詳情及手機尺寸樣式。
- `sw.js`：PWA 快取版本 2.4，包含新檔案。
- `AppsScript/`：原有後端程式，未變動，僅作部署備份。

## 重要說明

正式假日資訊以人事行政總處公布的辦公日曆為準。政府行政機關的休假制度與醫院、學校、私人企業的排班可能不同，故本版只提供日曆註記，不會自動判定任何家庭成員當天是否不用上班。
